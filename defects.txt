## DEFECT #1: Incorrect Route Name for Color Change
**Type**: Incorrect Documentation  
**Severity**: High  
**Location**: README.md, line 14

**Documented**:
```
Change color: `POST /change_color/<index>`
```

**Actual Implementation** (app.py, line 29):
```python
@app.route('/update_color/<int:index>', methods=['POST'])

```

**Issue**: The README documents the route as `/change_color/<index>`, but the actual implementation uses `/update_color/<int:index>`. This will cause a 404 error if users follow the documentation.

**Error Trace**:
```
POST /change_color/0 -> 404 Not Found
Correct: POST /update_color/0 -> 200 OK
```

**Impact**: Users following the documentation will be unable to change task colors.

## DEFECT #3: Missing Documentation for Color Parameter in Add Task
**Type**: Missing Documentation  
**Severity**: Medium  
**Location**: README.md, line 12

**Documented**:
```
Add task: `POST /add` with form: `title` only.
```

**Actual Implementation** (app.py, lines 13-17):
```python
@app.route('/add', methods=['POST'])
def add_task():
    title = request.form.get('title')
    color = request.form.get('color', 'white')
    tasks.append({'title': title, 'color': color})
```

**Issue**: The documentation states "with form: `title` only", but the implementation actually accepts an optional `color` parameter. The HTML form (templates/index.html) also includes a color input field.

**Missing Information**:
- The `color` parameter is optional when adding tasks
- Default color is 'white' if not specified
- Users can provide custom colors via the form

**Impact**: Users are unaware they can set task colors during creation, limiting their use of a key feature.

## DEFECT #6: Incomplete Installation Instructions for Windows
**Type**: Outdated/Incomplete Documentation  
**Severity**: Low  
**Location**: README.md, lines 3-8

**Documented**:
```bash
python -m venv .venv
source .venv/bin/activate
pip install Flask
```

**Issue**: The activation command uses bash syntax (`source .venv/bin/activate`) which doesn't work on Windows. The project is being run on Windows PowerShell.

**Correct Commands for Windows PowerShell**:
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install Flask
```

**Alternative for Windows CMD**:
```cmd
.venv\Scripts\activate.bat
```

**Impact**: Windows users following the documentation will fail to activate the virtual environment.
